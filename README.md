# BitChord

A peer-to-peer architeture to share files, like BitTorrent, using chord protocol.

## 💻 Tech Stack

[![Static Badge](https://img.shields.io/badge/Tauri-000000?style=flat&logo=Tauri)](https://v2.tauri.app/)
[![Static Badge](https://img.shields.io/badge/Rust-000000?style=flat&logo=Rust)](https://rust-lang.org/pt-BR/)
[![Static Badge](https://img.shields.io/badge/React-000000?style=flat&logo=React)](https://react.dev/)

Tauri is a framework for building web-based desktop applications, with Rust in the backend and several web frameworks in the frontend, such as React. It uses a webview to render the window and is known for making lightweight apps. It is similar to Electron.

## ▶️ Installing and running

``` Bash
cd tauri-app
npm install
npm run tauri dev
```
